Engineering Principles

Architecture before features.

I try to build systems with a strong foundation before adding complexity.

Correctness before scale.

Especially in financial systems, transactions, data integrity, authorization, and auditability matter more than simply making something fast.

Understand the system.

I don't want to only know how to use a framework. I want to understand what happens underneath it.

Build for real use.

The goal is software that solves real problems for real businesses.
